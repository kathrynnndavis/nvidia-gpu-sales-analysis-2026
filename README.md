# AI-Assisted NVIDIA GPU Sales Analysis (2026)

This project analyzes NVIDIA’s synthetic 2026 GPU sales dataset using Excel-based data visualization and AI-assisted insights. It combines traditional analytics with generative AI to produce business-ready interpretations, trend summaries, and a structured prompt engineering portfolio.

## 📊 Project Components

### 1. Dashboard & Charts
- Revenue Over Time
- Top GPU Models by Revenue
- Regional Sales Breakdown
- Price vs Units Sold

### 2. AI-Assisted Insights
AI-generated summaries interpreting each chart, focusing on:
- Revenue trends
- Product performance
- Regional demand
- Price elasticity

### 3. Prompt Engineering Portfolio
A structured set of prompts demonstrating:
- Trend analysis
- Pricing strategy recommendations
- Regional segmentation insights
- Demand elasticity interpretation

Each prompt includes:
- The prompt
- AI output
- Why the prompt works
- Business use case

### 4. Conclusion
Key takeaways about NVIDIA’s gaming, workstation, and AI compute GPU markets.

### 5. Next Steps
Suggestions for expanding the project using Python, additional charts, and deeper AI analysis.

## 🧰 Tools Used
- Microsoft Excel (PivotTables, charts)
- Microsoft Copilot (AI insights, prompt engineering)
- Word (final report)
- GitHub (project hosting)
